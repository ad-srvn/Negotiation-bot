# Game Theory Negotiation Project

The active, maintained implementation is in:

- `Project/`

Use that folder for all experiments, plots, tests, and presentation outputs.

## Quick Start

```bash
cd Project
python3.11 -m venv .venv311
source .venv311/bin/activate
python -m pip install -r requirements.txt
python scripts/run_all.py
```

The sequential run writes a clean, presentable bundle under (inside `Project/`):

- `results/presentation/run_YYYYMMDD_HHMMSS/`

From the workspace root, the same path is:

- `Project/results/presentation/run_YYYYMMDD_HHMMSS/`

See full instructions in:

- `Project/README.md`
